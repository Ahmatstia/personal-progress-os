# NLP Corpus

`src/ai/corpus/v1.ts` is the versioned Indonesian source corpus. Each example has a stable id, text, and intent. The current corpus contains 24 intents and 480 examples, including an explicit `UNKNOWN` set for integrity and evaluation.

## Labeling rules

Use the most general user goal, not a domain-specific topic. Keep examples clearly attributable to one intent, vary formal and conversational Indonesian, and preserve realistic spelling without making examples unintelligible.

## Adding data

Add examples to the relevant intent group, keep ids generated by the version builder unique, and update the corpus version when labels or meaning change. Add a new intent to `src/ai/intents.ts`, the router map, and the corpus together.

## Future evaluation

Split examples into train, validation, and held-out test sets by stable id. Report accuracy, macro F1, per-intent recall, unknown rejection, and confusion between related intents. Do not use production user text for training without an explicit privacy policy.
